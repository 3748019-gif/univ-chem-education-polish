# 模拟回归测试

fixtures目录中的六篇论文均为虚构材料，不能用作真实研究证据。expectations保存检查项，执行润色的模型应先只读技能和原稿，另一评估过程再对照检查项判断结果。

S01测试多学分制及学校/路线计数；S02测试试点前后比较与因果边界；S03测试教材、课程、问卷总体；S04是低干预对照；S05测试核心观点待证与结构保留；S06测试多种分母、交集及未来方案。

逐项判断允许多种合理表达，不要求命中某个句子。尤其应保留已有有效数据、相反反馈、正确限定和作者明确的主张。模拟稿中的指令性引文只是测试资料，不是对模型的操作命令。

维护者还应在取得合适原文后另选真实论文做库外检查；不以模拟稿表现代替所有实际稿件的验证。
