# 使用说明

## 准备材料

提供当前稿件、目标任务和修改边界。可以只提供一个段落，也可以提供完整论文或报告。若有多个版本，明确哪个是编辑基线；已有事实来源、表格说明或作者意见可一并提供。

普通润色不要求先补齐全部材料。模型应先完成现有证据支持的编辑，将真正影响判断的缺项集中列出。

## 常用请求

全文编辑：

> 使用 univ-chem-education-polish，保留这篇文章的原结构和主要观点，检查逻辑、措辞及结论口径，交付修改稿和集中补证清单。

报告改论文：

> 请在当前结构中把这份报告修改为化学教育论文。先核对研究问题、材料来源和比较维度，已有信息可以直接整理；未实际开展的方法不要补写。大幅结构变化先列方案。

局部核对：

> 只检查摘要、表2和结语是否使用一致的样本、分母、时间和结论范围，给出具体修改。

Word修订：

> 另存Word副本，以真实文字修订模式处理，保留原模板、表格、字体和版式；补证事项集中列在独立清单。说明实际完成的结构和视觉检查。

## 交付结果

一般包括修改后的正文及集中补证清单。清单写明位置、判断或数据、证据限度、所需材料和建议处理，避免只写“补充权威文献”。

用户可要求只输出正文、只审查逻辑或使用批注。需要作者裁定的核心论点可保留简短标记；标记对应的问题处理完成后，再形成投稿净稿。去掉标记不等于证据已补齐。

## 如何确认修改有用

- 原来的对象、单位、年级、实施状态和主要观点是否保持。
- 修正后的段落是否更清楚，是否引入重复限定或模板化套话。
- 建议是否对应前文发现，已经做过与计划做的事情是否区分。
- 补证清单是否指出具体缺口，并区别当前必需证据和后续研究。
- 表图、公式、引用和Word修订是否经过实际检查。

对事实来源的核查与语言润色是不同工作。需要更新学校方案、政策或投稿格式时明确提出取证任务，模型应记录所核对的原始来源和时间。
