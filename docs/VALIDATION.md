# 联合回归验证记录

核查日期：2026-11-25。本记录对应公开更新版本v1.0.1。此前公开版验证记录保留在[历史记录](VALIDATION-20261028.md)。

## 做了什么

在Antigravity既有首轮测试结束后，Codex与Antigravity共同审查6篇完整输出，修补实际发现的问题，再以独立新上下文执行候选回归。Antigravity界面及宿主记录的模型为Gemini 4 Neon Extra High；Codex测试使用当前会话继承模型。

共执行21次独立润色：Gemini 16次，Codex 5次；覆盖6篇既有模拟稿及3篇新留出稿。前两轮发现的问题保留在工作记录中，没有通过覆盖旧结果制造全通过记录。最终候选新增规则后进行了4次Gemini定点测试，以及2次Codex新稿/有效证据对照测试；未把前一候选版的全部结果冒称为最终候选的全量复测。

## 修复内容

- 区分检索总体、观察单位和可评价材料分母；计算余数不能自动赋予“现行”等未知状态。
- 保留程序状态、摘要原有观察与作者建议；未附底表或正文未展开不自动成为删换依据。
- 不从结果表反推检索、编码或核验过程，不把某类材料的方法扩展到其他材料。
- 对正文和补证清单中的新增判断都核对依据；描述性观察不自动增加显著性检验等任务。
- 修正S01-04预期记录的一处过强概括：“按各校文件口径记录”不代表已知各校科研归口不同。模拟输入未改，盲测者不读取预期。

## 安装包与验证边界

六种分发包已核对单一根目录、元数据、引用、编码、解包哈希及共用规则一致性。修改不改变既有平台封装方式。本轮真实模型运行仅覆盖Codex与Antigravity，没有新增WorkBuddy、Gemini网页或Claude账号内的执行验证。

这是Markdown文本编辑行为测试，没有编辑真实投稿稿件，没有验收Word分页或PDF版式；也没有重新通读153篇全文或核验其历史事实为当前事实。书目与文体观察仍用于定向参考。

本轮已在Codex与Antigravity完成覆盖安装核验，两端同名技能的共享核心文件哈希与最终候选一致。目录内容核验与当前会话缓存状态分别判断，不以安装文件一致代替所有客户端版本的运行保证。
