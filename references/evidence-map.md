# 规则与论文参照

本技能的方法参考153篇《大学化学》论文的既有编辑观察。书目见[索引](corpus-index.json)。索引提供定位与文体线索，不附原论文全文；使用者仍需为具体引文或事实取得原始来源。

下表为编辑方法的参照关系，不是逐篇格式统计或期刊官方要求。页数位置指参考PDF的文件页，可能与期刊页码不同。已发表文章仍可能有范围、时点或推理上的限制，应取其有用写法而非照搬结论。

## 可迁移的写法

| 编辑重点 | 参照及PDF文件页 | 应用方式 |
| --- | --- | --- |
| 研究身份与摘要动词一致 | P060页2、8；P073页2、6—7 | 调研、设计、实施和验证对应不同证据，不将建议写成已验证效果 |
| 对象和单位一起交代 | P060页2；P073页2；P058页2、4—5 | 学校、专业、路线、课程和问卷不能混作同一分母 |
| 用具体安排解释差异 | P058页4—5；P061页2—5；P057页2、7—8 | 描述目标、课程和规则，不由少数高校直接推全国教育优劣 |
| 建设背景与实际实施分开 | P071页4—7；P069页5—6；P063页2、5—6 | 国家建设、本校案例与作者建议各自保留身份 |
| 教学要求保留建议边界 | P077页8—9；P080页7；P058页5 | 建议表不自动成为所有高校必须照表开齐的现行标准 |
| 知识、能力和素质分别落实 | P077页3—4；P080页2—3 | 区分概念理解、任务表现和专业责任，不提高原动词程度 |
| 规模与效果分开 | P061页5；P134页6；P151页2、6—7 | 资源建设、申请和使用记录不直接代表学习提升 |
| AI应用保留层次和状态 | P084页2—5、7；P095页6—7；P075页2—4 | 科研工具、研究生培养与本科课堂不能混同 |
| 强度词与证据范围一致 | P060页2、8；P073页5；P134页6 | 百分比保留分母、年份、状态；发现数字不一时回原文核对 |
| 建议对应发现与条件 | P060页8；P058页5、7—8；P073页6—7 | 说明谁基于何种问题采取什么行动，不用新模式名称代替措施 |
